# Deck Type Arc Definitions

Loaded at start when deck_type is one of these types.
For Challenger and Why Evolve arcs, see deck-philosophy.md Section 4.

## account_plan

**Arc:** LANDSCAPE → WHITESPACE → HYPOTHESIS → PLAY → ASK

**Register:** Consistently moderate throughout — planning document aesthetic, not performance.

**Density budget:** 5-7 chunks per slide.

**Eval overrides:**
- S12-Space: N/A
- S4-Narrative: optional (planning documents follow logical flow, not dramatic arc)
- S5-Taste: "planning document test" — clean, scannable, reference-grade

**Rules:**
- No loss framing. No emotional appeals. Data-forward, hypothesis-driven.
- Reference-heavy, scannable, standalone without presenter.
- CTA: resource ask ("we need X to execute this plan")

## enablement_session

**Arc:** ORIENT → CONCEPT → DEMONSTRATE → PRACTICE → PATTERN

**Register:** Consistent clarity throughout — teaching register, not selling register.

**Density budget:** 7-9 chunks per slide (training content is inherently dense).

**Eval overrides:**
- S1-Hierarchy: hero element can be a screenshot or code block
- S2-Density: budget is 7-9 (higher than customer-facing)
- S5-Taste: clarity over polish
- S6-Proof: relaxed — product documentation is acceptable source
- S12-Space: N/A

**Training-specific layouts:**
- Annotated screenshot (hero = screenshot with callout overlays)
- Terminal/code (monospace code block with syntax highlighting)
- "Your turn" prompt (exercise with time estimate)

**PRACTICE slides must include:**
- Exercise prompt (what to do)
- Time estimate (how long)
- Expected output (what success looks like)
- Common pitfalls (what goes wrong)

## educational

**Arc:** PROVOKE → CONTEXT → DEEP DIVE → IMPLICATION → HORIZON

**Register:** High production value, magazine aesthetic — thought leadership quality.

**Density budget:** Varies by phase:
- PROVOKE: 2-3 chunks (dramatic opener)
- CONTEXT: 4-5 chunks
- DEEP DIVE: 7-9 chunks (technical depth)
- IMPLICATION: 3-4 chunks
- HORIZON: 2-3 chunks (end on an idea, not an ask)

**Eval overrides:**
- S5-Taste: HIGHEST bar — must look like a published editorial, not a sales deck
- CTA: disabled — closing is a thought/question, not an ask
- S12-Space: applies (PROVOKE and HORIZON should be spacious)

**Emotional engine:** CURIOSITY not FEAR. No loss framing anywhere.
Educational decks earn attention through intellectual generosity, not anxiety.

## qbr

**Arc:** RESULTS → ADOPTION → GAPS → ROADMAP → NEXT QUARTER

**Register:** Clinical and confident, consulting-firm aesthetic.

**Density budget:** 7-9 throughout. Tables with 5+ rows are justified and expected.

**Eval overrides:**
- S2-Density: higher ceiling (7-9 baseline, tables can exceed)
- S5-Taste: Tufte data-ink ratio — maximize data, minimize decoration
- S10-Text: smaller text OK for data tables (10pt minimum)
- S1-Hierarchy: charts and data visualizations serve as hero elements
- S12-Space: N/A (data density is the point)

**GAPS section rules:**
- Always on-slide, never hidden or minimized
- Yellow accent color for issues (not red — partnership tone)
- Shared loss framing only ("we" not "you")

**CTA:** Joint commitment ("we will..." not "you should...")

**Loss framing:** GAPS section only, always shared framing.
